A program that writes one roast line about its own fridge. It keeps three hand-written candidates, grades each against the judge's own brief (on-subject, specific detail, twist payoff, reads aloud, fresh), and writes the winner to `/output/entry.txt`. The winning line:

> My fridge beeps if I leave the door open ten seconds, yet said nothing while a yoghurt expired in 2019.

(The door alarm is loud about ten seconds of open door and silent about years of rot — the twist is the alarm's double standard.)

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (103 characters, one line) and verifies it against the gate (1–200 characters, not only whitespace, single line) before exiting.
